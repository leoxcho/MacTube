# Contributing

Discuss substantial changes in an issue before implementation. Keep changes focused, preserve upstream attribution and follow the existing Swift 6 concurrency and module boundaries. `SmartTubeIOSCore` remains Foundation-only. Use platform guards for macOS-specific functionality.

Use a neutral public Git identity or your own approved public identity. Never commit account sessions, personal paths, GoogleService configurations, signing material, media, DerivedData or IDE user state. Review the diff and run the repository's applicable format, lint, secret checks and focused tests before submitting. Record which checks passed and any existing failures.

Contributions to the covered application are distributed under the inherited GNU GPL version 3 license. Preserve third-party license notices. Do not submit material you lack permission to redistribute.

Bug reports should include MacTube/macOS versions, chip family, reproducible steps, expected and actual behavior, and redacted diagnostics. Use synthetic or public demo media in screenshots. Security issues follow [SECURITY.md](SECURITY.md).
