# Security reporting

Do not post credentials, cookies, account data or exploit details in a public issue.

Before publishing this repository, maintainers must enable GitHub private vulnerability reporting. Once enabled, use the repository's Security tab → Report a vulnerability. No personal email address is designated for security reports.

Until that private channel is configured, this local candidate has no supported external security reporting endpoint. Do not publish a sensitive report publicly as a workaround. Include affected version, impact and minimal reproduction steps through the private channel when available.

The prepared 6.0.1 candidate is not yet a supported public release. Updates and fixes are best effort; no response-time guarantee is made.
